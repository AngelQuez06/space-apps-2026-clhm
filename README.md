# space-apps-2026-clhm

Interactive pitch presentation demonstrating **CLHM** (*Interplanetary Survival Guide: Martian Map*), a live EVA route planner for Mount Sharp in Gale Crater powered by real NASA & USGS open datasets — **NASA Space Apps Challenge 2026**.

## Live Links
- **Live Web App:** https://www.clhm.cooking

## How to Run Locally
1. Clone or download this repository:
   ```bash
   git clone https://github.com/AngelQuez06/space-apps-2026-clhm.git
   cd space-apps-2026-clhm
   ```
2. Open the presentation using either method:
   - **Direct in browser:** double-click `index.html` to open it in Chrome, Edge, Safari, or Firefox.
   - **Local server (recommended):**
     ```bash
     python -m http.server 8000
     ```
     Then open `http://localhost:8000` in your browser.
3. **Controls:** use `→` / `←` (or click / swipe) to navigate slides, and press `F` for fullscreen.
