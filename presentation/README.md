# CLHM pitch deck (Spanish)

Full 17-slide deck in Spanish, with the speaker script.

Single-file HTML presentation for NASA Space Apps 2026 (CDMX).

## Open

Open `presentation/index.html` in a browser (double-click works, no server needed). Use Chrome or Firefox at full screen.

## Controls

- Next: right arrow, down arrow, space, Enter, click, or swipe left
- Previous: left arrow, up arrow, or swipe right
- `F`: full screen
- `#n` in the URL opens slide n (for example `index.html#8`)

## Speaker script

`pitch.md`: Spanish script per slide (about 4.5 min, three speakers), a 3-minute cut and likely judge questions.

## Other versions

- `../index.html` (repository root): short 7-slide version in English.
- `7-slides/index.html`: short 7-slide version in Spanish.
- `artwork/`: single-image keynote slides and the cover image.

## Contents

17 slides. Screens in `assets/screens/` are real captures of the app (laptop 1440×900, phone 390×844). `assets/qr.svg` points to https://www.clhm.cooking.

Figures checked on 2026-11-15: route timings measured against https://api.clhm.study (19 km route ≈ 0.3–0.45 s, storm evacuation ≈ 0.12 s, end to end); routable terrain block 1.20° × 1.61° ≈ 6,770 km²; 112 min comes from the app's route-decision panel.
